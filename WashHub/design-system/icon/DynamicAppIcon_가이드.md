# WashHub 다이나믹 앱 아이콘 시스템 가이드

## 개요
사용자의 마지막 세차일 기준으로 앱 아이콘이 자동 변경되는 5단계 다이나믹 아이콘 시스템.
"앱 아이콘이 당신의 세차 습관을 보여줍니다."

## 베이스 비주얼 스타일 (5개 아이콘 공통)
- 해상도: 1024×1024
- 정사각형 캔버스 (라운드 코너 미포함)
- 순수 검정 배경
- 미니멀, 프리미엄, 플랫 벡터 스타일
- 차량: 측면 스포츠 쿠페 실루엣 (모노크롬 실버/화이트/그레이)
- 대각선 비 (11시→5시 방향)
- 시안+화이트 동심원 물결 (차량 주변)
- 작은 물방울 산포
- 텍스트/글자 없음
- 동일 구도, 동일 앵글, 동일 스케일
- 오염도만 변화

## 아이콘 단계 정의

### STAGE 1 — JUST WASHED (0~2일)
- 완벽히 깨끗한 차체
- 밝은 실버/화이트 도장
- 후방 펜더 부근 강한 반짝임(스파클)
- 선명한 반사광
- 깨끗한 휠
- 신선한 물방울
- 프리미엄 광택 마감

### STAGE 2 — CLEAN (3~5일)
- 하단 사이드 스커트에만 아주 미세한 먼지
- 반짝임 약간 감소
- 대부분 깨끗
- 도로 먼지가 미세하게 시작

### STAGE 3 — NORMAL (6~10일)
- 하단 도어·후방 펜더에 눈에 띄는 먼지
- 약간의 빗물 자국
- 휠 약간 칙칙해짐
- 아직 수용 가능하지만 확실히 사용감

### STAGE 4 — DIRTY (11~20일)
- 하단 패널에 뚜렷한 때
- 후방 휠 아치 근처 진흙 튀김
- 광택 감소
- 로커 패널·펜더 주변 오염
- "곧 세차해야지" 느낌

### STAGE 5 — WASH ME (21일 이상)
- 심한 먼지·때
- 측면 전체에 큰 오염 영역
- 진흙+물자국
- 반짝임 거의 없음
- 확실히 세차 연체
- 감정적 트리거: 즉시 세차하고 싶게

## 디자인 규칙
- 오염 진행은 자연스럽고 사실적으로
- 후방 펜더·하단 차체부터 먼저 오염 누적
- 모든 단계에서 브랜드 아이덴티티 유지
- 만화적 과장 금지
- 단계 간 차량 모델 변경 금지
- UI 라벨·시간 라벨 추가 금지
- 프리미엄 자동차 미학 유지
- "청결도 진화"에 집중

## iOS 구현 방식
- `Assets.xcassets`에 `AppIcon` + `AppIconStage2~5` alternate icon set 등록
- `UIApplication.shared.setAlternateIconName()` 호출
- `Info.plist` → `CFBundleAlternateIcons` 키 설정
- 세차 기록 날짜 기준으로 자동 전환 (백그라운드 또는 앱 진입 시)

## 향후 확장 (Optional)
- 비 오는 날 상태
- 눈/제설제 오염 상태
- 황사/꽃가루 오염 상태

## 시스템 목표
```
사용자 세차 → 아이콘 깨끗해짐
세차 안 함 → 아이콘 점점 더러워짐
```
앱 아이콘이 세차 습관을 반영하는 감성적 경험 제공.
