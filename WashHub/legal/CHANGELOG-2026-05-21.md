## 1. 개인정보처리방침 변경 사항 (상세)

### 1.1 수집 항목 — "거부 시 영향" 컬럼 신설 (제1조)

기존 수집 항목 표에 **"거부 시 영향"** 컬럼이 추가되었습니다. 어떤 정보가 필수이고, 거부 시 어떤 제약이 있는지 한눈에 확인할 수 있습니다.

### 1.2 알림 관련 — 현재 미구현 기능 제거

> 외부 푸시 알림(FCM/APNs), 마케팅·광고성 정보 알림 발송 기능은 현재 앱에 구현되어 있지 않으므로, 관련 조항(푸시 토큰 수집, 야간 광고 동의, Firebase 위탁/국외이전 등)을 약관에서 제외했습니다.

- 좋아요·댓글·팔로우 등 활동 내역은 **앱 내 알림 화면**에서 본인이 확인하는 방식으로만 제공됨 (외부 발송 없음).
- 향후 푸시 알림 또는 마케팅 광고 알림 기능을 추가할 경우, 본 방침을 사전 개정하고 별도 동의를 받겠습니다.

### 1.3 얼굴 정보 처리 원칙 보강 (제1조 제3항)

- 회사는 이미지 내 얼굴 정보를 **개인 식별·인증 목적으로 처리하지 않으며, 생체정보로 수집·저장하지 않습니다.**
- 얼굴 모자이크는 이용자 선택사항이며, 모자이크 미적용 이미지 업로드 시 타인의 초상권 보호 책임은 이용자에게 있음을 명확히 명시.

### 1.3-1 이미지 저장 방식 정확 표기 (제1조 제3항·제6조·제11조)

기존: "업로드된 이미지는 Supabase Storage에 암호화되어 저장됩니다."
변경: **"Supabase Storage 에 원본 형식(JPEG 등)으로 저장되며, 접근은 Row Level Security 정책과 서명된 URL 로 제한됩니다. 저장 인프라(AWS S3) 차원의 서버측 암호화(SSE)는 자동 적용됩니다."**

> 사유: 기존 표현은 앱 레벨 암호화로 오인될 소지가 있었음. 실제 Storage 파일은 원본 형식으로 보관되며 인프라 차원의 SSE 만 적용됨. 안전성 확보 조치(제11조)와 국외이전 보호조치(제6조) 의 암호화 항목도 DB(PostgreSQL)와 Storage 의 적용 범위를 구분하여 명시.

### 1.4 보유기간 법적 근거 보강 + 탈퇴 즉시 삭제 + 신고/차단 이력 익명화 보존 (제3조·제9조)

- "내부 정책" → 구체적 사유로 변경.
- **탈퇴 회원 정보 30일 유보 조항 삭제** — 실제 코드(`withdraw-user` Edge Function)는 탈퇴 요청 시 profiles/auth.users/Storage 를 동시 즉시 삭제하므로(별도 cron/스케줄러 없음), 약관도 "탈퇴 즉시 완전 삭제, 복구 불가" 로 일치시킴.
- **신고/차단 이력 익명화 보존 구현 — 마이그레이션 #014**
  - 기존: ON DELETE CASCADE 로 탈퇴 시 신고/차단 record 함께 즉시 삭제 → 탈퇴-재가입 회피 가능
  - 변경: `reports.reporter_id` / `blocks.blocker_id` FK 를 SET NULL 로 전환, blocks 는 surrogate id PK + (blocker, blocked) partial unique 로 재구성
  - 탈퇴 시 본인 식별자만 NULL 익명화, 본문(대상/유형/시각)은 1년 보존 → 누적 위반 패턴 식별 가능
  - `pg_cron` + `cleanup_anonymized_reports_blocks()` 함수로 매일 KST 03:00 에 1년 경과 익명화 record 자동 파기
- 무상 SNS 특성상 전자상거래법·전자금융거래법·통신비밀보호법상 의무 보유 항목이 원칙적으로 없음을 명시.

### 1.5 처리 위탁 & 국외이전 분리 (제5조·제6조 신설)

기존: 제5조 하나에 위탁 정보만
변경: 제5조 (처리 위탁) + **제6조 (국외이전) 신설**

국외이전 고지사항 (「개인정보 보호법」 제28조의8):
- **이전받는 자:** Supabase Inc., Apple Inc., Google LLC
- **이전 항목·국가·일시·방법·목적·보유기간** 모두 명시
- **적법 근거:** 정보주체와의 계약 이행 (제28조의8 제1항 제3호)
- **보호조치:** Supabase와 DPA 체결, 저장 리전을 한국(ap-northeast-2)으로 설정, AES-256 저장 암호화

### 1.6 위치정보 처리 조항 신설 (제7조)

- 회사는 이용자의 **실시간 위치정보(개인위치정보)를 수집·저장하지 않습니다.**
- "주변 세차장 검색"·"날씨 정확도" 기능을 위해 위치 권한을 일시적으로 요청할 수 있습니다 (사용 중에만 허용).
- 권한이 허용된 경우라도 **원본 위·경도는 서버로 전송되지 않으며**, 기기 내에서 약 5km × 5km 단위의 기상청 격자(nx, ny)로 변환되어 격자 좌표만 전송됩니다.
- 권한을 거부해도 서울 기본 좌표 기준으로 정상 이용 가능.

### 1.7 만 14세 미만 아동 조항 (제8조) — 단일 조항으로 단순화

- 「개인정보 보호법」 제22조의2 에 따른 법정대리인 동의 의무를 회피하기 위해 약관상 만 14세 미만 가입을 금지함을 명시.
- 다만 사전 연령 확인 절차(소셜 계정 생년월일 수신 등)와 사후 삭제·정지 절차는 현재 코드에 구현되지 않았으므로 **약관에서는 가입 금지 단일 조항만 유지**.
- 향후 연령 확인 메커니즘 도입 시 본 조항 재개정 예정.

### 1.8 앱 접근 권한 안내 신설 (제12조)

「정보통신망법」 제22조의2에 따라 앱이 요청하는 권한별로 다음을 표로 명시:
- 권한 종류 (카메라·사진·위치·알림 등)
- 필수/선택 구분
- 거부 시 제한되는 기능

> "선택 권한은 거부해도 서비스의 핵심 이용에 제약이 없습니다."

### 1.9 자동화된 결정 조항 신설 (제13조)

### 1.10 개인정보 보호책임자 자연인화 (제15조)

기존: "만 14세 미만의 아동은 서비스에 가입할 수 없습니다." (단순 문구)
변경: **변경 없음** — 표준 SNS 패턴 그대로 유지. 사전 검증·사후 절차는 현재 미구현이라 약관에 명시하지 않음.

### 2.2 콘텐츠 라이선스 종료 시점 명확화 (제7조 제2항)

- 이용자가 게시한 콘텐츠에 부여한 비독점적 라이선스는 **이용자가 콘텐츠를 삭제하거나 회원 탈퇴를 완료한 시점에 종료**됨을 명시.
- 다만 다른 이용자에 의해 합법적으로 인용·공유된 콘텐츠는 해당 인용·공유 범위 내에서 계속 존재할 수 있음.
- 회사의 백업·통계·법적 의무 사본은 관계 법령에 따른 보존 기간 동안 유지될 수 있음.

### 2.3 협찬 표시 의무 강화 (제10조)

- 협찬 표시 기능을 사용하지 않거나 협찬 사실을 누락한 콘텐츠는 **「표시·광고의 공정화에 관한 법률」 및 공정거래위원회의 「추천·보증 등에 관한 표시·광고 심사지침」 위반**에 해당할 수 있음을 명시.
- 회사는 해당 콘텐츠를 사전 통지 없이 삭제할 수 있으며, 반복 시 계정 제한.
- 허위 표시의 법적 책임은 해당 이용자에게 있음.

### 2.4 정치·선거 관련 콘텐츠 정책 신설 (제6조·제8조)

- **금지 행위 명시 (제6조 이용자 의무)**:
  - 「공직선거법」 제250조 후보자 허위사실 공표 (7년↓ 징역 또는 500~3,000만원 벌금)
  - 「공직선거법」 제251조 후보자 비방 (진실한 사실이라도 처벌 가능)
  - 「공직선거법」 제82조의8 **딥페이크 선거 콘텐츠** (2024 신설) — 선거일 90일 전부터 AI 생성 합성 영상·음향·이미지를 선거운동에 이용 금지
  - 「정보통신망법」 제70조 명예훼손 / 제44조의7 불법정보 유통
  - 「형법」 제307·311조 명예훼손·모욕
- **허용 범위 명시**: 단순 지지·반대 표명, 정책 의견 등 합법적 정치 표현 (공직선거법 제82조의4)
- **회사 조치권**: 위반 콘텐츠 사전 통지 없이 삭제, 수사기관의 적법한 요청 시 자료 제공 가능

본 개정안은 한국 「개인정보 보호법」, 「정보통신망법」, 「위치정보법」 등 주요 법령에 부합하도록 작성되었습니다. 다만 다음 항목은 사업 형태(법인화 시점, 추후 위치기반서비스 신고, 결제 도입, 미성년자 콘텐츠 정책 등)에 따라 추가 검토가 필요할 수 있으므로 **앱스토어 출시 전 변호사의 정식 검토를 받을 것을 권고**합니다.

- 국외이전 적법 근거 (계약 이행 vs 별도 동의) — 가입 화면 UI 와 함께 검토 필요
- 위치정보법상 "위치기반서비스 사업자" 신고 의무 여부 — 향후 정책 변경 시 재검토
- 자동화된 결정 절차의 구체적 운영 (이의제기 처리 SLA 등)
- 14세 미만 확인 방식의 실효성 (소셜 계정 의존 한계)
- 콘텐츠 백업/통계 사본의 보존 기간 — 구체화 필요 시
- 표시·광고법상 협찬 표시 형식 (해시태그 #광고 #협찬 등 권장 표기)
- **공직선거법 제82조의8 (딥페이크 선거 콘텐츠) 정책 — 선거 기간 중 모니터링 방안, 신고 접수 프로세스, 자동 탐지 도구 도입 여부**
- **공직선거법 제251조 후보자비방죄 적용 시 "공공의 이익" 판단 기준** — 운영자의 사전 검토 어려움. 변호사·선거관리위원회 자문 권고
- **익명화 보존 콘텐츠가 추후 명예훼손·선거법 위반 사례에 사용되는 경우** — 작성자가 탈퇴해 식별 불가하나 콘텐츠가 살아있는 상황의 책임 소재 검토
