# WashHub — 스크린샷 촬영 가이드

> App Store Connect 에 등록할 스크린샷 준비 절차.
> Apple 요구사항 + WashHub 브랜드 일관성 기준.

---

## 1. Apple 필수 디바이스 사이즈

iOS 17 이상 기준, 다음 **2가지 사이즈는 필수** (나머지는 자동 스케일링):

| 사이즈 | 디바이스 | 해상도 (px) |
|---|---|---|
| **6.9"** ⭐ | iPhone 16 Pro Max | 1290 × 2796 |
| **iPad 13"** | iPad Pro 13" (M4) | 2064 × 2752 |

> 6.9" 가 없으면 6.7" (iPhone 14 Pro Max — 1290 × 2796) 로 대체 가능.
> iPad 미지원 앱이면 iPad 사이즈 생략.

## 2. 촬영할 화면 (8장 권장, 최소 3장)

| # | 화면 | 핵심 요소 |
|---|---|---|
| 1 | **로그인 / 시작 화면** | "WASHHUB" 로고 + "Sign in with Apple" + "비가 와도 세차" 슬로건 |
| 2 | **메인 피드 (홈)** | Wash Index 카드 (서울 90점 등) + Before/After 피드 1~2개 |
| 3 | **Before / After 슬라이더** | 피드 상세에서 슬라이더로 비교하는 순간 |
| 4 | **피드 작성** | 사진 선택 + 본문 + 차량 태그 + 협찬 토글 |
| 5 | **케미컬 라이브러리** | 카드형 리스트 + 별점 |
| 6 | **세차장 지도** | 서울 일대 마커 + 하단 카드 |
| 7 | **마이페이지** | 프로필 + 차량/세차 카운터 + 뱃지 |
| 8 | **루틴 상세** | 단계별 카드 + 사용 케미컬 |

## 3. 촬영 방법

### 옵션 A — Xcode 시뮬레이터 (권장)
```bash
# 시뮬레이터에서 ⌘ + S (또는 Device → Screenshot)
# 저장 위치: ~/Desktop
# 시뮬레이터: iPhone 16 Pro Max → iOS 18+
```

### 옵션 B — 실 디바이스
- 디바이스 + 잠금 버튼 동시 → 스크린샷 → AirDrop / Photos
- iPad Pro 13" 만큼은 실기기 권장 (시뮬레이터 픽셀 잘림 우려)

## 5. 사전 준비 (스크린샷 깔끔하게)

### 필수
- [ ] 시뮬레이터 상태바 정리: `xcrun simctl status_bar "iPhone 16 Pro Max" override --time "9:41" --batteryLevel 100 --cellularBars 4 --wifiBars 3`
- [ ] 데모 데이터 풍성하게 준비:
  - 메인 피드 — 3~5개 Before/After 피드 미리 게시
  - 케미컬 라이브러리 — 14개 시드 데이터 활용 (`sample_routines_equipments.sql`)
  - 세차장 — 시드 데이터 또는 직접 등록한 2~3곳
  - 마이페이지 — 차량 1대 + 세차 기록 5건 + 뱃지 1~2개

### 권장
- [ ] 라이트 모드 (현재 다크모드 미구현이라 자동)
- [ ] 한국어 로케일 — 시뮬레이터 설정 → Language → 한국어
- [ ] 시간대 — Asia/Seoul

## 6. 텍스트 오버레이 (Optional)

App Store 스크린샷은 순수 캡처 그대로 올려도 되지만, 마케팅 차원에서 텍스트 추가 권장:

| 화면 | 오버레이 텍스트 |
|---|---|
| 메인 피드 | **"세차 잘하는 사람들의 일상"** |
| Before/After | **"슬라이더 한 번에 차이가 보여요"** |
| 케미컬 | **"진짜 후기로 고르는 세차 용품"** |
| 세차장 지도 | **"내 주변 세차장, 한눈에"** |
| 마이페이지 | **"내 세차 리듬, 기록으로"** |

> Figma / Sketch / Canva 등으로 디자인 후 1290 × 2796 px 로 export.

## 7. 업로드

App Store Connect → My Apps → WashHub → App Store → Screenshots:
1. 디바이스 사이즈 선택 (6.9" 먼저)
2. 8장 (또는 준비된 수) 드래그앤드롭
3. 순서 조정 — 1번 스크린샷이 가장 노출됨
4. iPad 사이즈도 동일 절차 반복
